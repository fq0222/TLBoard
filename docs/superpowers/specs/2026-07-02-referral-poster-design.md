# 用户端推广海报设计

## 目标

在用户端“我的”页面的“我的推广”卡片中增加海报入口。用户点击后可在弹窗中查看带推广链接二维码的简洁推广海报。

## 交互

- PC 端：“海报”按钮位于“复制”按钮左侧。
- 移动端：“海报”和“复制”按钮保持同排，各占约一半可用宽度。
- 推广链接尚未加载或为空时，“海报”按钮禁用。
- 点击“海报”按钮后生成二维码并打开弹窗。
- PC 端和移动端均不显示弹窗顶部的“推广海报”标题。
- 弹窗支持 Element Plus 默认的关闭按钮和遮罩关闭行为。
- 二维码生成失败时不打开无效海报，并显示中文错误提示。
- 海报仅供展示，不提供下载、保存或系统分享功能。

## 视觉

海报沿用当前推广卡片的蓝绿渐变视觉，保持与用户端现有圆角、配色和按钮风格一致。

海报内容自上而下为：

1. 标题：“分享好友，余额奖励轻松拿”
2. 推广链接二维码
3. 二维码提示：“扫码注册”
4. 卖点：“AI 畅享 · 流媒体流畅 · 4K 高清体验”

二维码是主体，位于海报中间并保持足够留白和对比度。

## 响应式约束

- 桌面端使用适合海报阅读的固定最大宽度。
- 移动端弹窗宽度受视口宽度约束，保留两侧安全间距。
- 海报内容使用弹性尺寸，二维码最大宽度不超过容器，任何文案均可自然换行。
- 弹窗和海报不得产生横向页面滚动或溢出屏幕。

## 技术方案

- 仅修改 `client-user/src/views/user/My.vue`。
- 复用项目已安装的 `qrcode` 包，将推广链接生成为 Data URL。
- 复用 Element Plus 的 `el-dialog` 和消息提示能力。
- 不新增后端接口、路由、组件文件或依赖。

## 验证

- 执行用户端生产构建。
- 检查桌面端按钮顺序、弹窗开关和二维码内容。
- 检查小于 768px 的移动端按钮顺序与弹窗宽度，确认无横向溢出。
- 检查无推广链接和二维码生成失败的错误分支。
