# CF IP 测速配置共享设计

## 目标

将用户端三个 CF IP 优选入口的测速参数统一到一个共享模块，并将每个 IP 的测试次数调整为 2 次、单次超时时间调整为 2000 毫秒。

## 设计

- 新建 `client-user/src/utils/cf-ip-test-config.js`，导出测试次数、单次超时和测试间隔。
- `Profile.vue`、`Subscription.vue`、`CfOptimize.vue` 删除本地重复常量并引用共享配置。
- 保持 200 毫秒测试间隔、并发测速、IP 筛选和结果保存逻辑不变。
- 使用 Node 内置测试锁定共享配置值，最后执行用户端生产构建。

## 验收标准

- 三个页面都从同一模块读取测速参数。
- 每个 IP 测试 2 次。
- 每次测试在 2000 毫秒后中止。
- 用户端生产构建成功。
