# 首页无套餐轮播设计

## 意图

当用户端首页接口成功返回的全部套餐为空时，以大图轮播填补套餐展示区域，避免页面出现大面积无内容的空白，同时保持现有首页宽度和整体视觉节奏。

## 目标与非目标

- 仅在套餐接口成功且全部套餐为空（`plans.length === 0`）时展示轮播。
- 全部套餐为空时，轮播替换红框内的完整区域，包括“选择适合你的套餐”标题、分类按钮和套餐空状态。
- 某个分类为空但其他分类存在套餐时，继续使用现有“当前分类暂无套餐”状态，不展示轮播。
- 加载中继续展示骨架屏；加载失败继续展示错误信息和“重新加载”按钮。
- 本次轮播不增加文案、跳转链接、左右箭头或底部圆点，也不增加后台配置能力。

## 展示与交互

- 使用项目现有 Element Plus `el-carousel` 实现，不新增运行时依赖。
- 轮播图片按数字文件名升序排列，每 5 秒自动切换。
- 鼠标悬停时暂停自动切换。
- 隐藏左右箭头和底部指示圆点。
- 图片使用 `object-fit: cover` 和居中定位填满轮播，允许在不同屏幕比例下裁切边缘。
- 固定响应式高度：桌面端 745px、平板端 520px、手机端 320px；宽度沿用首页套餐内容区域宽度。
- 容器沿用首页视觉语言，使用圆角和溢出裁切，避免图片超出边界。
- 自动轮播不受系统“减少动态效果”设置影响，确保所有用户均按 5 秒间隔切换；页面其他装饰动画仍可单独尊重该设置。

## 图片资产

- 使用 `C:\Users\fq\Downloads` 中保留的 4 张数字文件名图片，按数字升序排列。
- 将原始 JPG、JPEG、PNG 转换为适合网页加载的本地 WebP 资产，保留原始宽高比，不修改下载目录中的源文件。
- 图片放入用户端项目的静态资源目录并随前端部署，不依赖外部图床。
- 首页通过 `import.meta.glob` 自动扫描 `client-user/src/assets/home-carousel/`，不在代码中逐张导入；增删受支持图片后重新构建即可生效。
- 自动扫描支持 PNG、JPG、JPEG、WebP 和 GIF，并按数字文件名升序生成轮播项。
- 用户已删除两张蜘蛛侠图片；技术实现仅处理当前保留的 4 张素材。

## 方案比较

### 采用：Element Plus Carousel

复用项目现有组件库，通过内置间隔、悬停暂停和过渡逻辑完成轮播。代码较少、行为稳定，且无需新增依赖。

### 未采用：自定义 Vue 定时器轮播

可以完全控制切换逻辑，但需要自行管理定时器、页面卸载、悬停、页面可见性和减少动态效果，当前需求没有足够收益抵消维护成本。

## 验证

- 增加前端逻辑测试，覆盖“全部为空显示轮播”“分类为空不显示轮播”等关键判断。
- 执行用户端生产构建，确认 Vue 模板、图片资产和样式无错误。
- 检查桌面、平板和手机三个断点的固定高度、裁切效果及无箭头/无圆点行为。
