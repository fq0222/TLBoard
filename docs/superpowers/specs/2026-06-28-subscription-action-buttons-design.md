# 订阅操作按钮视觉优化设计

## 目标

将首页和订阅页中的“重新优选 CF IP”“生成订阅链接”操作区从大尺寸卡片改为紧凑、明确的标准按钮，降低用户将其误认为说明卡片的可能。

## 视觉基准

采用用户确认的第三套“现代扁平”方案：

- 按钮高度保持在约 44–48px，满足移动端触控尺寸要求。
- 延续现有蓝色与绿色语义，使用比原卡片更清晰的浅色背景和同色边框。
- 左侧保留纯数字 `1`、`2`，取消数字圆形背景。
- 数字右侧使用低对比度同色竖向分隔线。
- 按钮底部增加约 2px 的同色强调线，强化可点击感。
- 按钮文字以整个按钮为基准居中，不受左侧序号影响。
- 删除原有说明小字和右侧操作图标。
- 取消大面积玻璃高光和厚重阴影，避免重新呈现为卡片。

## 响应式布局

- PC 端：两个按钮等宽左右排列。
- 移动端（小于等于 768px）：两个按钮保持原顺序上下排列。
- 移动端按钮占满可用宽度，不产生横向滚动。

## 交互状态

- 保留现有点击事件、加载文案和禁用逻辑。
- 悬停：背景色轻微加深，提供明确反馈。
- 按下：使用轻微缩放或下压反馈，不改变布局尺寸。
- 禁用：降低透明度、使用禁用光标，并移除悬停与按下反馈。
- 键盘聚焦：保留清晰的可见焦点轮廓。
- 系统开启减少动态效果时，关闭位移和缩放动画。

## 实施范围

- `client-user/src/views/user/Profile.vue`
- `client-user/src/views/user/Subscription.vue`

两处采用相同的模板结构和样式规格；不改变 API、数据状态、弹窗流程和业务逻辑。

## 验证

- 执行用户端生产构建。
- 检查两处页面不再包含按钮说明文字和右侧图标。
- 检查 PC 端横排、移动端竖排。
- 检查加载、禁用、悬停、按下和键盘聚焦状态。
