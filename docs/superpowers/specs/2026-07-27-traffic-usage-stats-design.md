# Traffic Usage Stats Design

## Goal

管理端新增“数据统计”页面，展示最近一轮 30 分钟流量同步中，每台被使用服务器的倍率后流量、使用人数和用户明细。

## Scope

- 只保存最新一轮统计结果，不保存历史数据。
- 统计数据来自现有 `traffic-manager` 计算出的本轮增量，不额外请求 3X-UI。
- 用户明细显示 email 和倍率后的统计流量。
- 页面提供当前统计时间点和刷新按钮。

## Backend Design

- 新增 `traffic_usage_current` 表，一行代表一台本轮有流量的服务器。
- 字段包含服务器 ID、服务器名称、本轮总流量、人数、用户明细 JSON、统计时间点。
- 在 `calculateUserTotalTraffic()` 已经算出用户在服务器上的倍率后增量时，生成服务器维度快照。
- 在同步事务里清空旧快照并写入新快照，保证页面只看到最新一轮数据。
- 新增管理端接口 `GET /api/admin/dashboard/traffic-usage` 返回快照列表、统计时间点和推荐显示单位。

## Frontend Design

- 管理端左侧导航在“仪表盘”下方新增“数据统计”。
- 新增 `TrafficStats.vue` 页面，用原生 CSS 绘制柱状图，避免增加图表依赖。
- 柱状图横坐标为服务器名称，纵向高度按本轮最大服务器流量比例计算。
- 人数显示为按钮，点击弹窗展示该服务器本轮用户 email 和倍率后流量。

## Verification

- 后端新增测试脚本覆盖快照计算、覆盖写入、读取格式。
- 管理端新增轻量源码测试，确认路由、导航、API 和页面关键结构存在。
- 前端执行构建验证。
