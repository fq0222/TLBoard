# 订阅二维码功能设计

## 目标

在用户端订阅工作区增加“查看订阅二维码”按钮，用户点击后可以查看官网地址、通用订阅二维码和 Clash 订阅二维码，方便移动端扫码导入。

## 按钮位置

按钮放在订阅工作区的步骤按钮区域，作为第 3 个同级操作：

1. 重新优选极速通道
2. 生成订阅链接
3. 查看订阅二维码

该位置与订阅生成流程一致，用户生成链接后能自然继续扫码。

## 弹窗内容

弹窗内容从上到下展示：

1. 官网地址
2. 通用订阅二维码
3. 文案：通用二维码
4. Clash 订阅二维码
5. 文案：Clash 订阅二维码

二维码内容分别使用当前页面已有的 `subscription.subscription_url` 和 `subscription.clash_url`。

## 视觉方案

按钮使用橙黄色系，与蓝色优选按钮、绿色生成按钮区分。二维码使用彩色方案：

- 通用订阅二维码：青蓝色
- Clash 订阅二维码：蓝紫色

两个二维码颜色不同，便于用户快速区分。

## 响应式规则

PC 端使用正常居中弹窗展示。移动端弹窗覆盖主要内容区域，但底部避让固定的 4 个 tab 导航；弹窗四周保留少量间隙，内容区域可滚动，避免小屏幕遮挡二维码。

## 实现边界

不新增后端接口，不改变订阅链接生成逻辑，不改底部导航结构。前端直接复用已有 `qrcode` 依赖生成 Data URL。
