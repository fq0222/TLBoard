当前推荐的页面结构

  • 登录后用底部导航替代移动端侧边栏，保留 `首页 / 订阅 / 帮助 / 我的` 四个一级入口。
  • `首页` 做成会员面板型工作台，重点展示套餐状态、流量进度、`CF IP 优选`、`生成订阅链接` 和系统公告。
  • `首页` 删除“服务与帮助”卡片，避免首页内容发散。
  • `订阅` 页聚焦核心动作，只保留 `优选 CF IP` 和 `生成订阅链接` 两个主按钮作为主要操作区。
  • `帮助` 保持内容型页面，移动端强化分类和文章卡片。
  • `我的` 聚合工单、订单、客户端下载、退出登录等服务入口。
  • 系统公告不再放在外部独立主入口，而是并入登录后首页，提高曝光。
  • 未登录 `首页/套餐页` 改成更强购买导向的移动端卡片布局，卡片内直接购买。
